# What is L2 Norm — 2026-07-30 15:26

## Definition

The **L2 norm** (also called the **Euclidean norm**) of a vector
$\mathbf{x} = (x_1, x_2, \ldots, x_n)$ is:

$$
\|\mathbf{x}\|_2 = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}
$$

It measures the straight-line (Euclidean) length of the vector from the origin.

## Why it matters in ML

- **Distance**: $\|\mathbf{a} - \mathbf{b}\|_2$ is the Euclidean distance between points.
- **Regularization**: L2 (ridge) regularization penalizes large weights via $\|\mathbf{w}\|_2^2$, which shrinks parameters and helps prevent overfitting.
- **Normalization**: Dividing a vector by its L2 norm produces a unit vector (length 1), common in embeddings and attention.

## Tiny example

For $\mathbf{x} = (3, 4)$:

$$
\|\mathbf{x}\|_2 = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = 5
$$
