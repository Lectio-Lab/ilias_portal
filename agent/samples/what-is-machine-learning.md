# What Is Machine Learning?

Machine learning (ML) is a branch of artificial intelligence where computers learn patterns from data instead of being explicitly programmed for every rule. A model is trained on examples, and then it uses what it learned to make predictions or decisions on new inputs. In practice, this means turning historical observations—such as student quiz results, sensor readings, or labeled images—into a function that generalizes beyond the training set.

A common distinction is between **supervised learning** (learning from labeled examples, like predicting exam scores from past assignments) and **unsupervised learning** (finding structure in unlabeled data, like grouping students by learning behavior). Many real systems combine both ideas with careful evaluation, because good performance on training data does not guarantee good performance in production.

For teaching, ML is useful when you want repeatable analysis at scale: recommending practice exercises, detecting topics students struggle with, or summarizing large course datasets. The key idea for beginners is simple: define a task, collect relevant data, train a model, evaluate it honestly, and only then deploy it where it helps students and instructors.
