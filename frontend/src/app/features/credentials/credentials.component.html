How login works

Click Refresh from ILIAS on My Courses. A browser window opens for Tübingen university login and MFA. Only session cookies are kept.

Your university password is typed in that browser window and is never written to Postgres or env files.

Security

  • No plaintext ILIAS password storage
  • Interactive MFA in a visible browser
  • Session cookies only on this machine
  • Optional username hint is display-only

Tip

After MFA succeeds, head to My Courses to browse and publish. If the session expires, refresh again and complete MFA once more.
