# ILIAS Portal Agent Kit

Ship ILIAS automation to any MCP-capable AI agent (Cursor, Claude Code, Claude Desktop, Codex, Gemini CLI).

## Quick start (macOS)

1. **Unzip** this folder anywhere (e.g. `~/ilias-portal-agent-kit`)
2. **Install:** `./install.sh` (checks Docker, Node 18+, Python 3.12+)
3. **Interactive auth:** run `./scripts/provision-interactive-auth.sh`
4. **Start:** `./start.sh`
5. **MCP:** use configs in `mcp-config/installed/` (generated by install)
6. **Skill:** copy `skill/ilias-portal/` to your agent's skills folder, or upload `ilias-portal-skill.zip` to Claude.ai
7. **University login:** refresh courses and complete login/MFA only in the visible browser window

## Sample chat prompts

- "Check my ILIAS setup"
- "Refresh my ILIAS courses" (complete MFA if browser opens)
- "Publish agent/samples/what-is-machine-learning.md as lecture slides"
- "Show contents of my default ILIAS course"

## Stop

```bash
./stop.sh
```
